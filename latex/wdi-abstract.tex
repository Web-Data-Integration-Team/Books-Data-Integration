\begin{abstract}
This project considers three different book datasets to combine information from different sources in a common schema. The datasets are a Goodreads dataset from Kaggle, book data from DBpedia, and an Amazon Books dataset from Hugging Face.
The datasets are expected to contain some of the same books, but they differ in their attributes, attribute names, and data formats. The goal is to identify matching books across the different sources and combine their information.

The three datasets contain between 20,981 and 52,478 records. The planned
integrated schema contains common attributes such as title, authors, publisher, publication date, number of pages, language, and genres. Depending on the source, additional information such as ratings, number of ratings, price, series, and awards is available. Matching books will be identified using a combination of
common attributes, especially title and authors. By integrating the three
sources, information about the same book can be combined in a common schema.


\end{abstract}

\section{Content}

\subsection{Use Case}

The goal of this project is to integrate book information from three different
data sources. The sources are expected to contain some of the same books.
However, they provide different information about the books and use different
attribute names and data formats.

The integration aims to identify matching books and combine their information
in a common schema. The resulting dataset can contain information such as title,
authors, publisher, publication date, number of pages, language, genres, ratings,
and price.


\subsection{Requirements Fulfillment}

\subsubsection{Datasets}

Three different datasets are used for this project: a Goodreads dataset from
Kaggle, book data from DBpedia, and an Amazon Books dataset from Hugging Face.
The Goodreads and Amazon datasets are provided in CSV format. The DBpedia data
was retrieved in XML format using a SPARQL query executed in Python. The SPARQL
query returned approximately 20,000 results. The DBpedia dataset used in this
project contains 20,981 entities.

Table~\ref{tab:overview} gives an overview of the three datasets, including their sources, formats, number of entities, and available attributes.

The project requirements are addressed as follows:

\begin{itemize}

    \item \textbf{Three different datasets:}
    The project uses three different data sources: Goodreads, DBpedia, and
    Amazon Books. This requirement is fulfilled.

    \item \textbf{At least 2,500 entities in the integrated dataset:}
    The three input datasets contain 52,478 entities (Goodreads),
    20,981 entities (DBpedia), and 40,000 entities (Amazon). All three
    datasets are also within the recommended range of 10,000 to 100,000
    entities. Since the datasets have not yet been integrated, the exact
    number of entities in the integrated dataset cannot be determined at
    this stage. However, based on the size of the input datasets, the
    required minimum of 2,500 entities is expected to be reached.

    \item \textbf{At least 1,000 entities contained in at least two datasets:}
    Since the datasets have not yet been integrated and the books have not
    yet been matched across the datasets, the exact number of shared entities
    cannot be determined at this stage. The expected overlap is discussed in
    the section \textit{Expected Entity Overlap}.

    \item \textbf{At least eight attributes in the integrated dataset:}
    The planned integrated schema contains 12 attributes and therefore meets
    this requirement. Books can be identified using a combination of at least
    two attributes. In particular, \texttt{title} and \texttt{authors} can
    be used for this purpose.

    \item \textbf{At least five attributes contained in at least two datasets:}
    Ten attributes of the planned integrated schema are available in at least
    two of the three input datasets. Seven attributes --
    \texttt{title}, \texttt{authors}, \texttt{publisher},
    \texttt{publicationDate}, \texttt{pages}, \texttt{language}, and
    \texttt{genres} -- are available in all three datasets. This requirement
    is therefore fulfilled.

    \item \textbf{At least one list attribute:}
    The planned integrated schema contains several list attributes, including
    \texttt{authors}, \texttt{genres}, and \texttt{awards}. This requirement
    is fulfilled.

\end{itemize}

The datasets also differ in their completeness. Attributes with more than
30\% missing values are marked with MV (Missing Values) in
Table~\ref{tab:overview}. In the Goodreads dataset, this applies to
\texttt{series}, \texttt{characters}, \texttt{edition},
\texttt{firstPublishDate}, \texttt{awards}, and \texttt{setting}.
In the DBpedia dataset, \texttt{genres}, \texttt{language}, and
\texttt{year} have more than 30\% missing values.

\subsubsection{Integrated Schema}

The attributes of the three datasets are mapped to a common schema (Table~\ref{tab:schema}).
Attributes that describe the same information but have different names in
the input datasets are mapped to the same attribute. For example,
\texttt{author} in Goodreads and \texttt{authors} in DBpedia and Amazon
are mapped to the common attribute \texttt{authors}. Similarly,
\texttt{publishDate}, \texttt{year}, and \texttt{publication\_date}
are mapped to \texttt{publicationDate}.

Table~\ref{tab:schema} shows the planned integrated schema and the corresponding
attributes in the input datasets. The planned schema contains 12 attributes.
Ten of these attributes are available in at least two datasets. The attributes
\texttt{title}, \texttt{authors}, \texttt{publisher},
\texttt{publicationDate}, \texttt{pages}, \texttt{language}, and
\texttt{genres} can be mapped to attributes from all three datasets.

The shared attributes can later be used to identify matching books across the
datasets. For example, a combination of \texttt{title} and \texttt{authors}
can be used for this purpose.

Some attributes differ in their representation and level of detail. For
example, DBpedia provides only the publication year, while Goodreads and
Amazon provide a publication date. Such differences have to be considered
during the integration process.

The datasets also provide different information about books. Goodreads and
Amazon contain rating information, while DBpedia does not. Goodreads provides
additional information such as series and awards, while Amazon also provides
subtitles. The integration can therefore combine information about a book
from different sources.

\subsubsection{Explanation}
The three datasets contain information about the same type of entities, but provide 
different information about them. For example, Goodreads and Amazon contain rating 
information, while DBpedia does not. Goodreads also provides information such as 
series and awards, while Amazon contains additional information such as subtitles. 
At the same time, several attributes, including title, authors, publisher, pages, 
language, and genres, are shared across all three datasets.

Therefore, integrating the datasets can provide more complete information about a 
book than using only one of the datasets. The shared attributes can also be used to 
identify books that occur in multiple datasets.

\subsubsection{Expected Entity Overlap}

The exact number of books that occur in more than one dataset is not yet known,
because the three datasets have not yet been matched. Since all three datasets
contain book data and share several attributes, some overlap between the
datasets is expected.
